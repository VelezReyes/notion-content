02
El Logotipo

Este es el logotipo oficial de BecaTech+. Tiene dos versiones autorizadas: negativa (sobre fondo oscuro) y positiva (sobre fondo claro). No se modifica, deforma, recolorea ni recompone fuera de lo establecido en este manual.

Versión oficial Logotipo completo · BecaTech+

El logotipo se construye sobre un módulo base (X), definido por el grosor del signo “+”. Esta retícula muestra las proporciones generales del logotipo en múltiplos de X.

Retícula de construcción

Alrededor del logotipo existe un área de reserva mínima de 2X en todos sus lados. Ningún texto, imagen, borde u otro elemento gráfico puede invadir ese espacio.

Área de reserva

Ejemplos básicos de lo que no se hace con el logotipo oficial. Estas reglas aplican en cualquier pieza, tamaño o soporte.

✕
No deformar ni estirar las proporciones.
✕
No usar colores fuera de la paleta oficial (solo crema o negro).
✕
No ubicarlo sobre fondos de bajo contraste.
✕
No agregar sombras, contornos ni efectos.
✕
No rotar ni inclinar el logotipo.

05
Sistema Modular

Tres ingredientes, infinitas combinaciones. Una arquitectura que cualquiera puede replicar: a mano, en código o con IA, sin perder consistencia.

01 · Tokens
/* Color */
--yellow: #F3FF00;
--green : #27CF77;
--purple: #A62BFF;
--cream : #EFEFE4;
--black : #000000;
/* Tipografía */
display: BookmanJF Pro;
cuerpo : Instrument Sans;
/* Espacio base */
grid   : 48px;
blur   : 90px;
radius : 2–3px;

Todo elemento del sistema se construye con estos valores. Cambiar un token actualiza toda la identidad simultáneamente.
